# Monster Arena

Monster Arena is a small C program I made to practice basic programming concepts like functions, loops, and user input. The game is a turn-based monster battle where the player chooses a monster and takes turns attacking an opponent until one of them reaches 0 HP.

## How to Compile and Run
To compile with GCC:

    gcc monstarena.c -o monstarena.exe

To run:

    monstarena.exe   (Windows)
    ./monstarena.exe (Linux)

## What the Game Includes
- Monster selection menu
- Different monsters with different stats/attacks
- Turn-based combat system
- HP updates after every move
- Win/Lose result at the end

## Why I Made This
I built this mainly to get more comfortable with:
- Writing larger programs in C
- Using functions to organize code
- Handling input and basic game logic
